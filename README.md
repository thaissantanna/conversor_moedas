💱 Conversor de Moedas Java Bem-vindo ao Conversor de Moedas Java, onde transformar R$ em $ (ou qualquer outra moeda) é rápido, fácil e divertido! 🎉

🚀 O que é isso? Este é um conversor de moedas feito em Java que permite você trocar valores entre as principais moedas do mundo 🌍. Ideal para quem gosta de viajar, planejar negócios ou simplesmente brincar com os números.

🖥️ Como funciona? Você verá um menu simples como este no terminal:

    1 - Real Brasileiro (BRL)
    2 - Dólar Americano (USD)
    3 - Euro (EUR)
    4 - Libra Esterlina (GBP)
    5 - Iene (JPY)
    6 - Dólar Australiano (AUD)
    7 - Franco Suíço (CHF)
    8 - Dólar Canadense (CAD)
    9 - Renminbi (Yuan) (CNY)
    10 - Peso Argentino (ARS)
Basta:

Escolher a moeda de origem. Escolher a moeda para onde quer converter. Digitar o valor que deseja converter. Pronto! 🎉 O programa faz o resto.
